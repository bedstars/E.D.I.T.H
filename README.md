# E.D.I.T.H (Fabric, Minecraft 1.21.4)

Build:  gradle build   (needs JDK 21; or copy src/ into the official Fabric example-mod template and run ./gradlew build)
Jar:    build/libs/edith-1.0.0.jar  -> put in .minecraft/mods together with Fabric API.
Use:    press I in-game. Paste your API key in the CORE tab.

Images: drop PNG/JPG/GIF files onto the menu, press the SHOT button, or press F9 in-game (rebindable) to attach
a screenshot. Up to 4 per message. Needs a vision-capable model.
